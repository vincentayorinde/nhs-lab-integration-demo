What this demonstrates

  • FHIR R4-style test order and report resources
  • HL7 v2-style result segmentation and basic field mapping
  • Patient, order and specimen ID reconciliation before mapping
  • Basic duplicate-message rejection and exception handling

What it does not demonstrate

Clinical safety case, production-grade HL7/FHIR validation, terminology-service integration, secured network transport, persistent SQL Server operations, real EPR/LIMS vendor integration or NHS accreditation. A sample SQL Server schema is included separately in the repository for further development.

Educational portfolio demonstration by Vincent Olagbemide. All entities and results are fictitious.
