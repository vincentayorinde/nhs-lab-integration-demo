About this project: Genflow is an independent software engineering portfolio exercise by Vincent Olagbemide, not a deployed hospital application. It implements browser-based state changes, identity checks, message formatting and audit entries, but its HL7 and FHIR messages are educational subsets, not clinically certified interoperability. No real patient data or NHS infrastructure is accessed.
